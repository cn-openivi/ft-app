# Русские описания опубликованных GitHub Releases FT170–FT181

Подготовлено по опубликованным релизам и истории изменений исходников. Один раздел — текст одного конкретного GitHub Release. Описание относится к реальным возможностям соответствующей сборки, а не к будущему плану разработки.

## FT170 — устойчивое подключение ICCOA и диагностика Android Auto

**Что добавлено**
- Автоматическое восстановление связи ICCOA при обрыве Bluetooth, управляющего или медиаканала: не более трёх попыток на один случай сбоя.
- Дополнительная настройка повторного запроса автомобильных датчиков для головных устройств, которым это необходимо. По умолчанию используется обычная событийная передача.
- Диагностика скорости и GPS автомобиля, включая сравнение с независимыми показаниями телефона.
- Тестовый переключатель «Всегда P» для Android Auto. По умолчанию выключен; фактическое положение селектора автомобиля остаётся основным источником данных.

**Что исправлено**
- Сохранение PIN только после подтверждённого успешного сопряжения; временная потеря связи больше не считается неправильным PIN.
- Повторные BLE-сканирования и отмена подключения без дублирующихся попыток.
- Обработка подписок Android Auto на датчики и корректное завершение каналов GPS, передач и звука при отключении.

**Статус:** тестовая сборка. Работа всех исправлений на автомобиле ещё не подтверждена.

---

## FT172 — быстрое повторное подключение без PIN (первая сборка)

**Что добавлено**
- **Quick Auth:** после первого успешного обычного сопряжения автомобиль можно подключать повторно без ввода PIN.
- Проверка доверенного автомобиля по криптографическим данным, а не только по названию или Bluetooth-адресу.
- Возможность вручную выполнить сопряжение с PIN и сбросить ранее сохранённое доверие при смене или сбросе головного устройства.
- Передача реального положения селектора автомобиля в Android Auto; «Всегда P» оставлено отдельной тестовой настройкой.

**Что исправлено**
- Защита от использования устаревших данных сопряжения и от автоматического PIN-входа при неподтверждённом доверии.
- Обработка нескольких вариантов ответов головного устройства при быстрой авторизации.

**Статус:** тестовая сборка. Quick Auth и поведение Android Auto требуют проверки на автомобиле.

## FT172 — обновлённая сборка: устойчивее Quick Auth при смене Bluetooth-адреса

Включает изменения первой сборки FT172.

**Что дополнительно исправлено**
- Повторное подключение к уже доверенному автомобилю при смене временного Bluetooth-адреса.
- Поиск головного устройства, даже если BLE-объявление не содержит его имени.
- Выбор подходящего автомобиля без переноса сохранённого доверия на постороннее устройство.

**Статус:** тестовая сборка. Рекомендуется вместо первой FT172 для проверки повторного подключения.

## FT173 — исправления автомобильного GPS и навигации Android Auto

**Что добавлено и исправлено**
- Подготовка и передача координат автомобиля для Android Auto с корректной обработкой отрицательных широты и долготы.
- Исправления сообщений навигации Android Auto и данных датчиков, необходимых для навигационного обмена.
- Улучшенная обработка автомобильной скорости и параметров GPS в ICCOA.
- Сохранены изменения Quick Auth из обновлённой FT172.

**Что проверить:** действительно ли Android Auto подписывается на автомобильные координаты и использует их в навигации. Наличие кода передачи GPS само по себе этого не доказывает.

**Статус:** тестовая сборка; использование GPS автомобиля самим Android Auto пока не подтверждено полевыми данными.

## FT174 — стабильнее GPS-виджеты и восстановление ICCOA

**Что добавлено**
- Приоритет автомобильного GPS в виджетах. Если сигнал автомобиля пропадает, предусмотрено переключение на GPS телефона с защитой от кратковременных обрывов.
- Отображение направления движения как компаса, а не как угла поворота интерфейса.

**Что исправлено**
- Устаревшие значения скорости и неверное отображение возраста GPS-данных.
- Восстановление соединения ICCOA после отдельных штатных закрытий управляющей сессии головным устройством.
- Передача навигационных данных Android Auto и диагностика доступных навигационных функций.

**Статус:** тестовая сборка. Исправления в коде не заменяют полевую проверку GPS и Android Auto.

## FT181 — видео без перекодирования, GPS/DR и улучшенный интерфейс

По сравнению с предыдущим опубликованным FT174 эта сборка включает накопленные изменения промежуточных версий.

**Что добавлено**
- **Два режима видео ICCOA:** обычное зеркалирование и дополнительный тестовый режим прямой передачи H.264 из Android Auto без повторного кодирования. Обычный режим выбран по умолчанию.
- Проверка совместимости видеопотока с возможностями головного устройства и автоматический возврат к обычному режиму при несовместимости. Вернуться к обычному режиму можно также с телефона.
- **Умная экономия ресурсов при трансляции:** уменьшение лишней частоты кадров при спокойном изображении и приоритет быстрого обновления после касания.
- **GPS и DR:** общий источник координат для виджетов и Android Auto, фильтрация и расчёт движения при временной потере спутников по проверенным данным автомобиля, калибровка скорости по колёсам.
- Запись диагностического GPS-трека при явном включении пользователем.
- Раздельное сохранение настроек видео, доверенного подключения и калибровки касаний для подтверждённых головных устройств.

**Что исправлено**
- Настройка плотности интерфейса по умолчанию — **240 DPI**, при этом личный сохранённый выбор не сбрасывается.
- Настройки разделены по выбранному протоколу: ICCOA или CarLife. Лишние сетевые порты скрыты до открытия расширенных параметров.
- Убраны необязательные упоминания конкретных марок телефонов и автомобилей и ошибочная пометка ICCOA как экспериментального протокола.
- Исправлена часть обработки поворота изображения, координат касаний, видеокадров и восстановления трансляции.

**Что проверить на машине**
- Работает ли прямой H.264 без ухудшения изображения и задержек; при проблемах переключиться на обычный режим.
- Получает ли Android Auto именно автомобильный GPS и продолжает ли корректную навигацию при потере спутников.
- Совпадают ли касания после поворота экрана и корректно ли сохраняется калибровка.

**Статус:** подписанная тестовая сборка. Проверка на автомобиле для этой версии на момент публикации не была завершена.
