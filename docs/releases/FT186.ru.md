# OpenIVI FT186 — тестовая версия для Toyota RAV4 XA60

**Подписанная сборка для вечерних полевых испытаний.** Приложение `app.ft.xa60`, версия 186, сертификат владельца как у FT185. Обновлять поверх предыдущей версии без очистки данных.

## Что исправлено

- **Первое сопряжение:** центральная круглая кнопка ОК уменьшена до радиуса 30–38 пикселей на виртуальном дисплее. Видимый круг и область определения попадания совпадают. Калибровка по четырём точкам остаётся запасной при промахе. Прямоугольное штатное китайское окно Toyota не менялось.
- **«Забыть доверенный автомобиль»:** удаляются все сохранённые ключи для меняющихся идентификаторов Toyota, а не только старый PRIMARY. Удаляются remembered BLE и старый PIN; личная идентичность телефона сохраняется. Если операция записи не удалась, FT сообщает об ошибке.
- **Прямое видео Android Auto H.264:** первый IDR кадр теперь сохраняется при переходе с FT-кодировщика, передаётся в новую RTP-очередь и отмечается отправленным только после фактической записи Direct key frame в транспорт. Новый ключевой кадр не требуется только потому, что режим сменился.
- **Резервный видеотракт:** при ошибке Direct возвращаем стандартную композицию. Проверяется, что через неё действительно отправляются кадры; если нет — один запрос IDR. Без бесконечных попыток переключаться обратно.
- **Касания Android Auto:** сохранён точный пересчёт Direct, правильное использование сохранённой четырёхточечной калибровки и отключение калибровки по выбору пользователя.
- **Bluetooth:** сохранены механизмы FT186 по отдельному состоянию автомобильных HFP/A2DP профилей, без неподтверждённого обещания, что Toyota поддерживает все функции.
- **GPS/DR:** обычная отправка автомобильного GPS в AA сохранена. Полноценный инерциальный DR без достоверных OEM входов пока не подтверждён.

- **Локализация:** дополнительные сообщения Bluetooth включены в ресурсы всех поддерживаемых языков; в курдских переводах пока используется понятный английский текст по умолчанию до проверки носителями.

## Программа тестирования

На стоянке: проверить новое подключение без очистки данных, кнопку «Забыть» → свежий Normal PIN → последующий Quick Auth; попасть точно в маленькую ОК и проверить резервные четыре точки. Затем Android Auto сначала в Direct H.264, проверить отсутствие чёрного экрана и блочных артефактов, касания по краям. Переключить на обычное видео и убедиться в восстановлении картинки и звука. Сохранить полный диагностический ZIP.

**Статус до результатов автомобиля: FIELD_NOT_TESTED.** CI, тесты и подпись не подтверждают правильный вывод видео на реальном ГУ. При сбое используйте обычный видеотракт.
