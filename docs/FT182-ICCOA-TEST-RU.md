# FT182 — короткая памятка испытаний ICCOA / A13 / GPS

**Статус: APK FT182 ещё не собран. Эта инструкция для будущего полевого запуска, а не отчёт об испытании.** Один тестовый телефон; все проверки только на стоянке. Для китайского RAV4/Wildlander соответствие приёмника определяется фактическим подключением, а не названием модели.

1. Откройте FT → «Настройки» → «Автомобиль и подключение» → протокол **ICCOA Carlink**. Если FT запрашивает обязательные разрешения, разрешите их по подсказкам.
2. На ГУ откройте ICCOA Carlink; в FT нажмите поиск автомобиля, выберите найденное ГУ и подключитесь. Если появляется код на ГУ, введите его в FT; при успешном Quick Auth код не нужен.
3. На ГУ откройте экран FT, нажмите несколько плиток и выполните прокрутку. Для A13 откройте список приложений: если на телефоне установлен пакет с двумя разными значками LAUNCHER, убедитесь, что оба видны и каждый открывает **свой** экран (название пакета и имена Activity фиксируются в диагностике, если доступны; устанавливать лишние приложения ради теста не обязательно).
4. Откройте Android Auto и навигатор на той же машине. **Не отключайте геолокацию телефона.** Дождитесь работающего GPS автомобиля, если он предоставляется ICCOA. Запишите лишь факт GPS, без личных координат.
5. В FT на вкладке **Журнал/Log** сформируйте ZIP-отчёт. Внутри должен быть `aa-car-gps-evidence.txt`. Нам нужны статусы объявления GPS, открытия SENSOR, получения реального `SensorRequest(LOCATION)` и записи GPS-пакета. Отсутствие запроса — допустимый отрицательный результат; работа Google Maps от телефона не считается доказательством автомобильного GPS.
6. Если тестируется SuperCast, отдельно проверьте сопряжение Wireless debugging и разрешение проекции экрана. Не вводите код сопряжения в переписку и не прикладывайте секреты.
7. После теста передайте **только ZIP FT и краткое замечание, что не сработало**; экспертная оценка производится по логам.

Сравнение FT self-mode и Google Desktop Head Unit делается **на этом же телефоне**, но требует отдельного компьютера и не выполняется этой простой памяткой. Техническая трёхветочная процедура (FT self-mode / DHU ADB / DHU USB AOA с Location ON и негативным контролем): [FT182 GPS A/B](FT182-AA-CAR-GPS-SUBSCRIPTION.md).

Тесты JUnit, сборка и проверки на ГУ пока НЕ ПРОВЕДЕНЫ. Нельзя утверждать GPS Android Auto по одному факту записи пакета в сокет.
